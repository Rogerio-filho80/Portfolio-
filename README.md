# Rogério Ambrósio Mussi Filho | Portfólio Profissional

Este é o portfólio profissional de **Rogério Ambrósio Mussi Filho**, Desenvolvedor Full Stack e Engenheiro de Software. O site foi desenvolvido com foco em experiência do usuário, design moderno e responsividade total.

---

## 🎯 Objetivo

Apresentar minha trajetória profissional, habilidades técnicas, projetos desenvolvidos e qualificações para potenciais clientes e empregadores. O site funciona como um currículo interativo e uma plataforma de apresentação técnica.

---

## 📋 Funcionalidades Principais

- **Design Moderno e Responsivo**: Interface completamente responsiva que funciona em desktop, tablets e smartphones.
- **Modo Claro/Escuro**: Toggle dinâmico para alternar entre tema claro e escuro com persistência no localStorage.
- **Navegação Otimizada**: Menu fixo com scroll suave e links anchor para todas as seções.
- **Barra de Acessibilidade**: Funcionalidade "Pular para o conteúdo" para usuários de leitores de tela.
- **Currículo para Download**: Botão de download direto do arquivo PDF do currículo.
- **Formulário de Contato**: Formulário funcional com validação em tempo real e integração com envio (futuramente com backend).
- **Currículo Interativo**: Componente de currículo com abas (Formação, Skills, Experiência) para navegação eficiente.
- **SEO Otimizado**: Metatags completas, Open Graph tags, Twitter Cards e JSON-LD Schema Markup para melhor indexação em buscadores.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando tecnologias modernas e web standards:

- **HTML5**: Estrutura semântica e acessível.
- **CSS3**: Estilização avançada com variáveis customizadas, flexbox, grid e animações.
- **JavaScript Puro**: Toda a lógica do site é implementada com vanilla JavaScript, sem dependências de frameworks.

### Principais Features em JavaScript:

- **Theme Toggle**: Gerenciamento dinâmico do tema claro/escuro.
- **Menu Mobile**: Toggle responsivo com animação suave.
- **Smooth Scrolling**: Rolagem suave para navegação entre seções.
- **Header Observer**: Animação do header ao rolar a página.
- **Form Validation**: Validação em tempo real dos campos do formulário.
- **Auto Typewriter**: Efeito de digitação automática na seção de hero.
- **Modal View**: Visualização em modal para o currículo.
- **Footer Year**: Atualização automática do ano no footer.

## 🚀 Como Executar o Projeto

### Pré-requisitos

- Um navegador moderno (Chrome, Firefox, Edge, Safari).
- (Opcional) Node.js e npm para desenvolvimento futuro.

### Instalação e Execução

1. **Clone o repositório** (ou baixe os arquivos):
```bash
git clone https://github.com/Rogerio-filho80/Portfolio-.git
```

2. **Abra o arquivo `index.html`** em seu navegador:
```bash
open index.html  # No macOS
# ou
start index.html # No Windows
```

## 📱 Testes e Validações

### Responsividade

Para testar a responsividade, utilize as ferramentas de desenvolvedor do navegador:

1. Pressione **F12** para abrir as ferramentas de desenvolvedor.
2. Clique no ícone de "Toggle device toolbar" para alternar entre dispositivos.
3. Teste em diferentes tamanhos de tela:
   - Desktop (1920px, 1440px, 1024px)
   - Tablet (768px, 600px)
   - Mobile (375px, 414px)

### Acessibilidade

- Verifique a navegação por teclado (tecla Tab).
- Confirme que os contrastes de cores atendem aos padrões WCAG.
- Teste com leitores de tela (VoiceOver, NVDA, TalkBack).

### SEO

Verifique as metatags no `<head>` do HTML e os dados estruturados JSON-LD.
